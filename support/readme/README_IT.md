# Doorstep — README

English README: [README.md](../../README.md)

Doorstep is a free, open-source app that shares files between your phone and your computer over your own Wi-Fi — no internet, no cloud, no accounts. Pair once, and files move by themselves.

- Download: https://github.com/javex-12/Doorstep/releases/latest
- Download page: https://javex-12.github.io/Doorstep/
