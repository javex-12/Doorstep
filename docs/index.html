How it works

Pair your phone and computer once with a QR code — after that, files dropped on your PC land on your phone automatically.

1

Connect to same Wi-Fi

Ensure both your phone and computer are on the same Wi-Fi router, local network, or phone hotspot.

2

Scan QR Code Once

Open Doorstep on your computer and scan the QR code using your phone camera. Choose Personal device to pair permanently.

3

Drop Files & Done

Drag files into your Doorstep folder on your computer — they instantly stream directly to your phone.

⚠️ Installation Guide & Safety

Doorstep is distributed directly via GitHub open-source releases. Your device OS may present a standard security popup for third-party APKs/EXEs.

📱 Android Play Protect Notice

If Android displays "Google Play Protect doesn't recognize this app":

  • Tap More details
  • Tap Install anyway
  • Doorstep is 100% open source — this warning only shows because it is downloaded directly from GitHub rather than sold on Google Play.

🖥️ Windows SmartScreen Notice

If Windows SmartScreen shows "Windows protected your PC":

  • Click More info link
  • Click Run anyway button
  • This notice appears for any new portable executable file that isn't signed with an expensive commercial certificate.

✅ 100% Private & Open Source

Your privacy is guaranteed by mathematics and open code. Doorstep sends data strictly across your own local Wi-Fi router. No remote servers receive your payload.

🔄 Zero Configuration Needed

No port forwarding, static IP setups, or router tweaks required. Doorstep automatically discovers paired local devices using UDP multicast.

Frequently Asked Questions

Got questions? We've got answers.

Why isn't Doorstep on Google Play or Microsoft Store yet?

Doorstep is open-source and free software. Store listings require developer subscription fees and review queues, so releases are hosted on GitHub first. Direct store packages are planned for upcoming releases.

Does it work when the internet is completely down?

Yes! Doorstep operates locally over Wi-Fi, Ethernet cables, or mobile phone hotspots. It does not touch the internet at all.

Is there an iOS / macOS version coming?

Yes, Apple platform support (iOS / macOS) is currently in development. Currently, Doorstep natively supports Android and Windows.

How does Doorstep compare to LocalSend?

Doorstep is built on top of the LocalSend protocol core (Apache-2.0). It adds QR code persistent device pairing, background drop zones, auto-reconnection, and automatic folder synchronization.
