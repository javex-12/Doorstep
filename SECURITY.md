# Security Policy

Doorstep takes security seriously. Transfers are end-to-end encrypted over TLS
with per-device certificates and mandatory client-certificate verification —
your files never touch a server.

## Reporting a Vulnerability

**Please do not open a public issue for security problems.**

Instead, report privately through the GitHub security advisory form:

- https://github.com/javex-12/Doorstep/security/advisories/new

You can also reach the maintainer directly via the [portfolio contact page](https://cydercoder.vercel.app).

## What to include

- The affected version(s)
- A clear description of the vulnerability
- Steps to reproduce, if possible
- Any proof-of-concept code (without sensitive data)

## Response timeline

- **Acknowledgment:** within 3 business days
- **Status update:** within 7 business days
- **Coordinated fix:** as soon as a patch is ready (usually within 30 days for
  confirmed issues)

We appreciate the community's help in keeping Doorstep safe. Validated reports
are credited in the release notes (unless anonymity is requested).
